# Cattle Health Monitoring System 🐄

Flask-based web application for monitoring cattle health using
temperature, heart rate, and motion data with ML-based prediction.

## Tech Stack
- Python
- Flask
- TensorFlow / Keras
- scikit-learn
- HTML, CSS, JS

## How to Run
```bash
python -m venv env
env\Scripts\activate
pip install -r requirements.txt
python app.py
